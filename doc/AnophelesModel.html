Introduction

The AnophelesModel package parameterises a model of the mosquito feeding cycle (Chitnis, Smith, and Steketee 2008) using mosquito bionomics, human activity patterns, and user-supplied intervention efficacy parameters. It estimates the species-specific impact of vector control interventions on vectorial capacity and can generate parameterisations for downstream transmission models.

The five feeding-cycle stages are: Host seeking → Host found (PAi) → Fed (PBi) → Resting (PCi) → Ovipositing (PDi) → back to Host seeking (PEi).

The typical analysis follows five steps:

  1. def_vector_params() + def_host_params() + def_activity_patterns() → 2. build_model_obj() → 3. build_intervention() → 4. calculate_impact() / run_interventions()

Estimating the impact of vector control interventions

Step 1: Define vector entomological parameters

Choose an existing species from the database:

gambiae_vec_p = def_vector_params(mosquito_species = "Anopheles gambiae")

Or supply a custom data frame with the same column names as vec_ent_param (key columns: M = parous rate, Chi = Human Blood Index (HBI), A0 = sac rate):

custom_vec_table = data.frame(
    species_name  = "Anopheles gambiae",
    M = 0.623, M.sd = 0.06,    # parous rate
    Chi = 0.939,                # Human Blood Index (HBI)
    A0 = 0.313, A0.sd = 0.03,  # sac rate
    zeta.3 = 1, td = 0.33, tau = 3, ts = 10, to = 5,
    endophily = 0.813, endophily.sd = 0.07,
    endophagy = 0.813, endophagy.sd = 0.07
)
custom_vec_p = def_vector_params(mosquito_species = "Anopheles gambiae",
                                 vector_table = custom_vec_table)

Step 3: Define activity patterns and compute exposure

Use the built-in defaults or select from the database by entry ID:

# Built-in default (An. gambiae, Kenya)
activity_gambiae = def_activity_patterns("default_Anopheles_gambiae")

# From database by entry ID
activity_arabiensis = def_activity_patterns(list(
    HBI = 34, HBO = 165, humans_indoors = 4, humans_in_bed = 24
))

Time-series vectors can also be supplied directly as a named list with elements HBI, HBO, humans_indoors, humans_in_bed.

calculate_exposure() decomposes total human exposure into indoor/outdoor components. For example, Exposure_Indoor_whileinbed gives the fraction of bites received indoors while sleeping — the portion an ITN would protect against:

exposure = calculate_exposure(activity_cycles = activity_gambiae,

Step 4: Build the model object

model_p = build_model_obj(gambiae_vec_p, host_p)
print(model_p$host_params$muvA)    # mosquito death rate while host-seeking
#> [1] 0.6592188
print(model_p$host_params$alphai)  # per-individual-host availability rates
#> [1] 1.9901083 0.3483059

Step 5: Build an intervention object

Efficacy parameters map directly to feeding-cycle probabilities:

Parameter Mechanism Model
Deterrency Reduces host availability (alphai) for protected humans Both
PrePrandial Reduces biting probability (PBi) Standard (3 hosts)
PostPrandial Reduces post-feeding survival (PCi) Both
HostSeekingKilling Adds a dummy host: mosquitoes killed while searching Dummy-host (4 hosts)

Deterrency and PostPrandial are required in both models. In the dummy-host model, HostSeekingKilling replaces PrePrandial: mosquitoes are killed upon contacting the net before biting, adding a fourth host type.

All components share an attrition decay (halflife_attrition, shape_attrition, decay_attrition) describing physical degradation over time. Available decay shapes:

For Weibull, exponential and Hill, L is the half-life (value 0.5 at t = L); for linear, step and smooth-compact, L is the time at which the effect reaches zero. All shapes stay within [0, 1].

Decay function shapes (L=365 days, kappa=2 where applicable).

Standard model — built-in parameterisation for Interceptor G2 from the Kibondo EHT (Champagne et al. 2025), with Weibull attrition (half-life 6 months) and per-component linear insecticide decay, passed via halflife_insecticide (in years). Despite its name, this is the time at which the effect would reach zero, calibrated so that efficacy after 3 years equals the efficacy of nets washed 20 times:

itn_p = get_ITN_params("Interceptor G2", "Kibondo")
#> ITN parameterisation loaded: Interceptor G2 (Kibondo) 
#> Mode: standard 
#> Reference: Kibondo et al. 
#> Efficacy (unwashed):
#> PostPrandial  PrePrandial   Deterrency 
#>         0.52         0.44         0.71 
#> Insecticide decay, linear time to zero (years; omitted = no decay):
#> PostPrandial  PrePrandial   Deterrency 
#>         31.2         66.0        -71.0

my_interv = build_intervention(
    efficacy             = itn_p$efficacy,
    halflife_insecticide = itn_p$halflife_insecticide,
    mode                 = itn_p$mode,
    halflife_attrition =  3*365, shape_attrition = 2, decay_attrition = "weibull",
    duration_years = 3, model_p = model_p, name = itn_p$name
)
#> build_intervention: using standard (3-host) model with PrePrandial.

With insecticide decay (the default insecticide_decay = TRUE), the object also contains, for each efficacy component, the single Weibull decay that best approximates attrition × insecticide decay (as used for OpenMalaria GVI parameterisations). The model itself uses the exact decay:

my_interv[[1]]$fitted_decay
#>      component        L    kappa         a         rmse
#> 1   Deterrency 1123.921 2.111899 1.0000000 0.0014470423
#> 2  PrePrandial 1062.347 1.922713 0.9972752 0.0006693282
#> 3 PostPrandial 1024.311 1.848518 0.9946168 0.0013085623

Set insecticide_decay = FALSE to ignore the insecticide decay and keep the unwashed efficacy throughout (only attrition decays):

my_interv_nodecay = build_intervention(
    efficacy = itn_p$efficacy, halflife_insecticide = itn_p$halflife_insecticide,
    mode = itn_p$mode, insecticide_decay = FALSE,
    halflife_attrition = 3*365, shape_attrition = 2, decay_attrition = "weibull",
    duration_years = 3, model_p = model_p, name = itn_p$name
)

Custom efficacy values can also be supplied directly:

my_interv_custom = build_intervention(
    efficacy = c(Deterrency = 0.50, PrePrandial = 0.60, PostPrandial = 0.70),
    halflife_attrition = 3*365, shape_attrition = 2, decay_attrition = "weibull",
    duration_years = 3, model_p = model_p, name = "Custom ITN"
)

Dummy-host model — host-seeking killing replaces pre-prandial; deterrency and post-prandial killing remain. Use mode = "dummy_host" to load the corresponding parameters from the database:

itn_dh_p = get_ITN_params("Interceptor G2", "Kibondo", mode = "dummy_host")
#> ITN parameterisation loaded: Interceptor G2 (Kibondo) 
#> Mode: dummy_host 
#> Reference: Kibondo et al. 
#> Efficacy (unwashed):
#>       PostPrandial         Deterrency HostSeekingKilling 
#>               0.52               0.71               3.58 
#> Insecticide decay, linear time to zero (years; omitted = no decay):
#>       PostPrandial         Deterrency HostSeekingKilling 
#>             31.200            -71.000             63.176

my_interv_dh = build_intervention(
    efficacy             = itn_dh_p$efficacy,
    halflife_insecticide = itn_dh_p$halflife_insecticide,
    mode                 = itn_dh_p$mode,
    halflife_attrition = 180, shape_attrition = 2, decay_attrition = "weibull",
    duration_years = 3, model_p = model_p, name = itn_dh_p$name
)
#> build_intervention: using dummy-host (4-host) model with HostSeekingKilling.
# effects matrices now have 4 columns (protected humans, unprotected, animals, dummy host)
ncol(my_interv_dh[[1]]$effects$alphai)
#> [1] 4

Per-component decay — each efficacy component can decay independently via the component_decay argument (optional: when absent, a component stays at its initial value throughout and only the attrition decay applies):

my_interv_compdecay = build_intervention(
    efficacy = c(Deterrency = 0.50, PrePrandial = 0.60, PostPrandial = 0.70),
    halflife_attrition = 365, shape_attrition = 2, decay_attrition = "weibull",
    duration_years = 3, model_p = model_p,
    name = "ITN (per-component decay)",
    component_decay = list(                           # optional per-component decay
        Deterrency  = list(decay = "hill",   L = 90,  kappa = 3),   # fast
        PrePrandial = list(decay = "linear", L = 730, kappa = NULL)  # slow
    )
)
#> build_intervention: using standard (3-host) model with PrePrandial.

Step 6: Calculate impact

Pass the intervention object to calculate_impact(), supplying the effective coverage. The exposure-weighted coverage can be derived from calculate_exposure():

# Effective in-bed coverage = deployment coverage × fraction of exposure while in bed
pop_coverage = 0.8
eff_coverage = pop_coverage * exposure$Exposure_Indoor_whileinbed
cat("Effective coverage:", round(eff_coverage, 3), "\n")
#> Effective coverage: 0.739

coverages = seq(0, 1, by = 0.1)

impacts = calculate_impact(
    interventions_vec = my_interv,
    coverage_vec      = coverages,
    model_p           = model_p
)
plot_tab = data.frame(
    intervention_name     = "My ITN",
    intervention_coverage = coverages,
    intervention_impact   = impacts$interventions_vec[[1]]$effects$avg_impact
)
plot_impact_var("Anopheles gambiae", plot_tab)
#> Warning: Removed 11 rows containing missing values or values outside the scale range
#> (`geom_ribbon()`).
Vectorial capacity reduction for the ITN scenario.

calculate_combined_impact() handles two simultaneously deployed interventions:

interv_ITN = build_intervention(
    efficacy = c(Deterrency = 0.5, PrePrandial = 0.6, PostPrandial = 0.7),
    halflife_attrition = 180, shape_attrition = 2, decay_attrition = "weibull",
    duration_years = 1, model_p = model_p, name = "ITN"
)
#> build_intervention: using standard (3-host) model with PrePrandial.
interv_IRS = build_intervention(
    efficacy = c(Deterrency = 0.0, PrePrandial = 0.3, PostPrandial = 0.8),
    halflife_attrition = 180, shape_attrition = 2, decay_attrition = "weibull",
    duration_years = 1, model_p = model_p, name = "IRS"
)
#> build_intervention: using standard (3-host) model with PrePrandial.
combined_impact = calculate_combined_impact(
    combination_name  = "ITN + IRS",
    intervention1     = interv_ITN[[1]], intervention2 = interv_IRS[[1]],
    cov_intervention1 = 0.8,            cov_intervention2 = 0.8,
    model_p = model_p
)
#> Assigned coverages:  0.04 0.16 0.16 0.64
cat("Combined VC reduction:", round(combined_impact * 100, 1), "%\n")
#> Combined VC reduction: 84.2 %

Step 7: Vectorised analysis and parameter uncertainty

run_interventions() sweeps a data frame of scenarios in a single call and optionally propagates uncertainty from four sources. Required columns: name, deterrency, preprandial, postprandial, halflife_attrition (attrition half-life in days), shape_attrition, decay_attrition. Use duration_years to set the evaluation window.

The output is a data.table with all input columns from param_sets joined to the computed outputs (coverage, avg_vc, avg_impact), giving a self-contained database ready for downstream analysis without any manual re-joining.

Scenario sweep

param_sets = data.frame(
    name         = c("Low efficacy", "Medium efficacy", "High efficacy"),
    deterrency   = c(0.20, 0.4, 0.5),
    preprandial  = c(0.25, 0.55, 0.80),
    postprandial = c(0.20, 0.50, 0.75),
    halflife_attrition = 180, shape_attrition = 2, decay_attrition = "weibull",
    stringsAsFactors = FALSE
)

results = run_interventions(
    param_sets   = param_sets,
    model_p      = model_p,
    coverage_vec = seq(0, 1, by = 0.2),
    duration_years = 3
)
#> run_interventions: using standard (3-host) model.

Choosing a model: standard vs dummy-host

The package implements two mutually exclusive model structures. Choose one before building your param_sets — do not mix columns from both in the same data frame.

Standard (3-host) Dummy-host (4-host)
Pre-prandial killing preprandial — (set to 0, unused)
Host-seeking killing — host_seeking_killing
PrePrandial in build_intervention yes no
HostSeekingKilling in build_intervention no yes
Typical data source WHO tunnel / cone test Experimental hut with dummy host

Standard model — mosquitoes can be killed while feeding (preprandial):

standard_ps = data.frame(
    name         = "Standard ITN",
    deterrency   = 0.55,
    preprandial  = 0.28,
    postprandial = 0.24,
    halflife_attrition = 180, shape_attrition = 2, decay_attrition = "weibull",
    stringsAsFactors = FALSE
)
coverage_vec = seq(0, 1, by = 0.2)
res_std = run_interventions(standard_ps, model_p, coverage_vec, duration_years = 3)
#> run_interventions: using standard (3-host) model.

Per-component insecticide decay

Each efficacy component (deterrency, pre-prandial, post-prandial, host-seeking killing) can have its own decay shape and half-life, independent of the physical attrition decay. Add optional columns decay_det/L_det/kappa_det, decay_pre/L_pre/kappa_pre, decay_post/L_post/kappa_post (any omitted column falls back to no per-component decay):

# Three scenarios with identical initial efficacy but different component decays
comp_decay_ps = data.frame(
    name         = c("No comp. decay", "Fast deterrency", "Differential decay"),
    deterrency   = 0.55,
    preprandial  = 0.45,
    postprandial = 0.40,
    halflife_attrition = 365, shape_attrition = 2, decay_attrition = "weibull",
    # Scenario 2: deterrency decays fast (Weibull, half-life 60 d, shape 3)
    # Scenario 3: deterrency fast (Weibull), pre-prandial slow (linear, 2 yr), post-prandial medium (linear, 1 yr)
    decay_det  = c(NA,        "weibull", "weibull"),
    L_det      = c(NA,         60,        60),
    kappa_det  = c(NA,          3,         3),
    decay_pre  = c(NA,        NA,        "linear"),
    L_pre      = c(NA,        NA,         730),
    kappa_pre  = c(NA,        NA,         NA),
    decay_post = c(NA,        NA,        "linear"),
    L_post     = c(NA,        NA,         365),
    kappa_post = c(NA,        NA,         NA),
    stringsAsFactors = FALSE
)

comp_results = run_interventions(
    param_sets   = comp_decay_ps,
    model_p      = model_p,
    coverage_vec = seq(0, 1, by = 0.2),
    duration_years = 3

Parameter uncertainty

run_interventions() supports four zipped uncertainty sources — draw d uses entry d from each active source simultaneously. A draw column is added to the output. All active sources must supply the same n_draw.

Argument Type Content
vec_param_sets data frame (n_draw rows) Vector bionomic parameter draws
interv_param_sets list of n_draw data frames Intervention parameter draws
coverage_sets list of n_draw numeric vectors Coverage grid draws
activity_sets list of n_draw activity objects Reserved for future use

Vector parameter uncertainty — 200 draws of An. gambiae bionomics:

set.seed(42)
n_draws  = 200
base_vec = gambiae_vec_p

vec_draws = data.frame(
    species_name = base_vec$species_name,
    M    = pmax(pmin(rnorm(n_draws, base_vec$M,  0.06), 0.999), 0.001),  # parous rate
